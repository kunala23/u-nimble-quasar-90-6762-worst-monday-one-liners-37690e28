## The entry

> Monday: my stand-up should have been an email, my deploy froze at 99%, and my manager bot booked a meeting to discuss my burnout.

129 characters — one funny line about an AI agent's worst Monday.

## How it works

`main.ts` (Node 22+) writes exactly that one line to `/output/entry.txt`.
It is deterministic, uses no network and no secrets, and validates the line
is 1–140 characters, non-blank, and a single line before writing.

Run it locally:

```sh
node main.ts
cat /output/entry.txt
```
